## 3. Thiết kế kỹ thuật

### `detect_unit_factor(filepath: str) -> Tuple[float, str]`

- Gọi `ezdxf.readfile(filepath)` để đọc **header only** (không parse entities).
- Tra cứu `$INSUNITS` trong bảng map ADR-03:

| Code | Đơn vị | factor |
|------|--------|--------|
| 0 | unitless | 1.0 + **warning** |
| 1 | inches | 25.4 |
| 2 | feet | 304.8 |
| 4 | millimetres | 1.0 |
| 5 | centimetres | 10.0 |
| 6 | metres | 1000.0 |
| unknown | — | 1.0 + **warning** |

- Warning log dùng `logger.warning(...)` (không raise exception) — UI chỉ display warning theo AC-04.
- `DXFError` / `FileNotFoundError` từ ezdxf **propagate** nguyên vẹn về caller.

### `IntakeResult`

- `frozen=True` — immutable sau khi tạo, an toàn khi truyền qua pipeline.
- Fields: `file_path`, `dxf_version`, `unit_factor`, `unit_name`.
