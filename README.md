# RoomQS Project

Phần mềm tự động hóa tính toán diện tích và xuất dữ liệu từ file AutoCAD (DXF) ra file Excel.

## Yêu cầu hệ thống
- Python 3.11.x
- AutoCAD 2019 trở lên

## Hướng dẫn cài đặt cơ bản
1. Clone repository này về máy:
   ```bash
   git clone <repo-url>
   ```
2. Cài đặt các thư viện phụ thuộc:
   ```bash
   pip install -r requirements.txt
   ```
3. (Các bước chạy chương trình sẽ được cập nhật sau)
